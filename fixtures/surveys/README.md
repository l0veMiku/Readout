# 合成导出样例

这些文件只模拟平台表头与编码，不含任何真实问卷回答。

| 文件 | 模拟内容 | 期望 |
|---|---|---|
| wjx-system.csv | 问卷星系统列 + `第N题(选项)` 0/1 + 其他文字 | 系统列忽略；两个选项列合成一道多选 |
| tencent-multi.csv | 腾讯 `题:子项` 1/空 + `[选项填空]` | 三个选项列合成一道多选；建议列按开放题 |
| qualtrics-matrix.csv | `Q5_1..Q5_4` + `NA` + `_TEXT` | 矩阵合成题组；NA 计缺失；文本列不进入选项 |
| forms-scale.csv | `Timestamp` + 单列 1–5 + 开放评论 | 单列量表低置信；评论按开放题 |
